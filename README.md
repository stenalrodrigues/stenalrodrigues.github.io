# Personal Data Science Portfolio

A responsive dark-themed portfolio website built with HTML, CSS, and a small amount of JavaScript. It is designed to be hosted for free with GitHub Pages.

## Included
- About section
- Education and learning journey
- Skills and methods
- Featured Power BI e-commerce analytics project
- Contact links
- Responsive mobile navigation

## Before publishing
Replace these placeholders in `index.html`:
- `Your Name`
- `YOUR-GITHUB-USERNAME`
- `YOUR-REPOSITORY`
- `YOUR-LINKEDIN-USERNAME`
- `YOUR-EMAIL@example.com`
- `[University name]`

Only include skills and experience you can confidently discuss. The project preview is a stylised mockup, not a screenshot of the actual Power BI report. You can add your own dashboard screenshots to `assets/` later.

## Publish on GitHub Pages
1. Create a GitHub repository. For a personal site, name it `YOUR-GITHUB-USERNAME.github.io`. Or use a normal repository name and enable Pages.
2. Upload `index.html`, the entire `assets` folder, and `README.md` to the repository root.
3. Open repository **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. Wait a few minutes. Open the published URL shown on the Pages settings screen.

## Link your Power BI project
In `index.html`, replace the sample URL `https://github.com/YOUR-GITHUB-USERNAME/YOUR-REPOSITORY` with the URL of your actual Power BI project repository.
